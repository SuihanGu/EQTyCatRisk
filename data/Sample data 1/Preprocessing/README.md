# 日本地震—台风耦合事件数据（1946—2026）

本目录面向后续网页查询、地图展示与接口开发，汇总了日本内陆地震与台风耦合识别结果。名义研究时段为 **1946—2026 年**；基于当前两套目录和既有识别结果，实际识别到的耦合地震时段为 **1951—2024 年**。1946—1950 年、2000 年以及 2025—2026 年没有进入本次汇总的已识别事件；这表示当前目录/识别结果中无记录，不应直接解释为这些年份绝对不存在耦合灾害。

## 1. 耦合时刻信息.csv

每行表示一组唯一的“地震—台风”耦合事件，按 `eq_time` 从新到旧排序。

| 字段 | 含义与单位 |
|---|---|
| `z_id` | 稳定关联键，格式为 `EQ-{原地震ID}__TC-{台风编号}`；可与完整路径表连接。 |
| `coupling_type` | `Simultaneous`：正负 72 小时内；`EQ-TY`：先地震后台风；`TY-EQ`：先台风后地震。 |
| `eq_time` | 地震时刻，UTC，ISO 8601。 |
| `eq_lat`, `eq_lon` | 地震纬度、经度，十进制度。 |
| `Mw` | 地震震级。1946—1999 部分来自 USGS 的 Mw/相应矩震级字段；2001—2024 源目录仅提供 `Mag` 数值而未提供统一震级类型，因此沿用用户要求的列名 `Mw`，使用时应保留此来源限制。 |
| `tc_time` | 与地震形成耦合判定的台风路径时刻，UTC，ISO 8601。 |
| `tc_lat`, `tc_lon` | 该时刻的台风中心纬度、经度，十进制度。 |
| `wind_ms` | 该时刻台风 10 分钟平均风速，m/s。 |
| `dt_hours` | `eq_time - tc_time`，小时。正值表示台风在先，负值表示地震在先。 |
| `distance_km` | 地震震中与该时刻台风中心的大圆距离，km。它不是地震到 R34 边界的距离。 |
| `R34_km` | 该时刻估算的 34 kt 风圈半径，km。 |

## 2. 满足耦合条件的完整台风事件集.csv

这是长表格式的完整路径表。每个 `z_id` 对应多行，且组内按 `times` 升序排列。

| 字段 | 含义与单位 |
|---|---|
| `z_id` | 与耦合时刻表相同的唯一关联键。 |
| `coupling_type` | `Simultaneous`、`EQ-TY` 或 `TY-EQ`。 |
| `times` | 台风路径时刻，UTC，ISO 8601。 |
| `lats`, `lons` | 台风中心纬度、经度，十进制度。 |
| `winds` | 台风 10 分钟平均风速，m/s；早期 IBTrACS 个别时刻没有可用风速或气压时保留为空值。 |

“完整周期”指源台风目录中该台风编号/SID 的全部可用路径点，而不是仅截取风速达到 34 kt 或地震发生附近的时段。2001—2024 年目录中的 0 kt 记录也被保留，以保持源路径周期完整。

## 关键换算和来源说明

- 风速统一由 kt 转为 m/s：`m/s = kt × 0.514444`。
- 1946—1999 年 IBTrACS 路径优先使用 `TOKYO_WIND`，其次使用 `WMO_WIND`；均缺失时根据 `TOKYO_PRES`/`WMO_PRES` 估算 10 分钟平均风速。
- 气压估算式：`V1min = 6.7 × (1010 - P)^0.644`，再用 `V10min = 0.88 × V1min`。
- 1946—1999 年路径坐标优先使用 `TOKYO_LAT`、`TOKYO_LON`，缺失时回退到 IBTrACS 的 `LAT`、`LON`。
- 2001—2024 年路径来自日本台风目录，使用 `台風番号` 连接完整路径。
- 所有时间均转换或解释为 UTC；网页前端若显示日本当地时间，可再转换为 Asia/Tokyo（UTC+9），但不要覆盖原始 UTC 字段。

## 网页开发建议

1. 以 `耦合时刻信息.csv` 作为事件索引和筛选表。
2. 用户打开某个事件时，按 `z_id` 从完整路径表提取全部路径点，并将 `lons/lats` 组成折线。
3. 用 `tc_time` 在该折线上高亮耦合时刻，用 `eq_lon/eq_lat` 绘制地震点，用 `R34_km` 绘制风圈。
4. 前端将 `coupling_type` 作为枚举，不要依赖中文标题解析。
5. 生产环境建议把两个 CSV 转为数据库表、Parquet 或 GeoJSON；`z_id` 应设为主键/外键并保持不变。
6. 对震级科学比较或跨目录统计前，必须检查上文所述 2001—2024 年 `Mw` 列的震级类型限制。

## 复现方法

在 Windows PowerShell 中运行：

```powershell
python .\代码\build_web_coupling_dataset.py
```

脚本默认使用本研究机器上的 F 盘数据路径。迁移到其他机器时，可通过 `--pre-result`、`--post-result`、`--ibtracs-file`、`--usgs-file`、`--post-earthquake-file`、`--post-typhoon-file`、`--loss-dir`、`--shapefile` 和 `--output-dir` 参数覆盖路径。运行时会检查 `z_id` 唯一性、路径覆盖、耦合类型、时间排序、R34 和距离值，并把摘要写入 `原始数据/汇总处理审计.json`。

## 原始数据与完整性

- `识别结果原始快照`：汇总前的两代耦合识别表。
- `原始目录源文件`：USGS 地震目录、IBTrACS 全球台风目录、2000 年以后地震目录和台风目录的原始副本。
- `耦合台风损失事件CSV`：本次 129 组事件涉及的台风损失源表，只复制实际被耦合事件引用的文件。
- `NaturalEarth_日本行政区底图`：地图绘制所需 shp 及其配套文件。
- `文件清单_SHA256.csv`：准备包内文件的相对路径、字节数和 SHA-256，可用于迁移后完整性核验。

原始目录的版权、许可和引用要求仍分别遵循 USGS、NOAA IBTrACS、Natural Earth 及日本相关数据提供方的规定。
